# Git Workflow Documentation

## Git

Git is a distributed version control system used to track changes in source code.

## Branching

Branches allow developers to work on different features independently.

## Pull Request

A Pull Request is used to propose changes from one branch to another and allows code review before merging.

## Merge

Merge combines changes from different branches.

## Rebase

Rebase moves commits onto another base commit and creates a cleaner linear history.

## Git Stash

Git stash temporarily stores uncommitted changes so that the working directory can be cleaned.

## Git Tags

Tags are used to mark important points in Git history, such as software releases.

## Git Workflow

Feature branch → Pull Request → dev → Pull Request → main
